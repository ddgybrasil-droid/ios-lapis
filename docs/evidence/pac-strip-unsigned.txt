## before
- After pthread features seed, launchd died OS_REASON_SIGNAL ns=2 / 0x5
- GDB: first userspace BRK was `esr=f2000001` (`brk #0x1`), not libpthread
  `#0xb001`. PAC auth on unsigned Auth64 pointers (`autda`/`blraa`/`retab`)
  and/or landing in TEXT padding `brk #1`.

## patch
1. Rewrite PAC ops across DSC TEXT + `/usr/lib/dyld` + `/sbin/launchd`:
   - sign hints → NOP; AUT* → XPACI/XPACD/XPACLRI
   - RETAA/B → RET; BLRAA/BRAA → BLR/BR
   - MOVK diversity immediately before BLRAA/BRAA → XPACI on addr reg
   - BRK #0xc470..#0xc473 → NOP
2. `--nop-brk1`: rewrite TEXT padding `brk #1` → NOP (~6.45M words).
   Needed for bring-up: surgical patches at a guessed unslid PC did not
   clear the trap (guest still executed `brk #1`); blanket nop does
   (`nbrk=0`). Side effect: fallthrough into the next function is possible.
