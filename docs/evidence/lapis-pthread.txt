What it does
- xnu/lapis_pthread/lapis_pthread.c: freestanding port of libpthread-539
  kern/kern_support.c (bsdthread_register, bsdthread_create/terminate,
  thread_selfid, workq create/destroy/markfree threadstack, workq_setup_thread,
  workq_handle_stack_events). Uses the kernel's own _pthread_callbacks.
  Returns PTHREAD_FEATURE_SUPPORTED (0x400001df: incl. KEVENT 0x40,
  WORKLOOP 0x80), mutex_default_policy = ULOCK. psynch_* -> ENOTSUP
  (not hit by launchd so far: 0 calls in all runs).
- Table version 0 (same as pthread.kext) -> xnu calls bsdthread_register.
- Blob (4988 B) lives in the _copyio_test cave (16888 B, sysctl-only test;
  its entry now returns ENOTSUP); _pthread_functions (0xfffffe000724c538)
  -> lapis_pthread_functions (0xfffffe0007993e80) instead of stub
  0xfffffe000756a800.
- ABI note: Darwin arm64 packs stack args by natural size and passes all
  varargs on the stack; GCC does not. mach_vm_map_external's cur/max/inh are
  passed as (u64)(cur|max<<32), inh; panic() is called without varargs.
  (First attempt panicked in vm_sanitize_err_compat_cur_and_max_prots.)
