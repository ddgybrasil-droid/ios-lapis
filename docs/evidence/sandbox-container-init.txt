  description _container_init(): sandbox_get_container_expected() failed: -1`

## patch
In dyld_shared_cache_arm64e.31, _container_init call site VA 0x1e2776ea0:

  add/add/bl/cbnz  →  strb 0,strb 0,mov w0,#0,nop

So expected=0 and the following `cmp #1` / `b.ne epilogue` skips
containerization. Tool: tools/patch_fullroot_container_init.py
