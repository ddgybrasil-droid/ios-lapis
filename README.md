# ios-lapis

Экспериментальный порт iPadOS на Lenovo Yoga Tab Plus TB520FU. Текущее
состояние и границы проверки — в `docs/ROUND-0020.txt`.

В этой ветке на копии исходников раунда 0014 закрыта запись UFS и block,
убран `setRootMedia-noop` и убраны boot-аргументы, которые обходят entitlement
или отключают panic-проверки. Образ из этих исходников не собран. Старые
`.img` не соответствуют этой правке и не являются готовым fastboot-образом.

Архив раунда 0015, диагностический ZIP раунда 0016 и JSON fixup раунда 0019
в доступной папке Drive не оказались. Image4 и AMFI не интегрированы.
